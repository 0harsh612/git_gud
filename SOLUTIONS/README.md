# Solutions Directory

Welcome to the **SOLUTIONS** folder!

This directory is where workshop participants store their personal copies of the arena challenges, puzzles, and bug fixes without stepping on each other's toes.

## How to Set Up Your Solutions

1. **Fork & clone** this repository to your computer.
2. In the repository root, run:
   ```bash
   python my_dir_setup.py
   ```
3. The script will automatically detect your GitHub username from your remote origin and generate your folder:
   ```text
   SOLUTIONS/<your-github-username>_solutions/
   ├── basics/
   ├── intermediate/
   ├── advanced/
   ├── miscellaneous/
   └── assets/
   ```
4. Work on the code inside your personal folder, fix the bugs, pass the testcases, run the boss levels, commit your changes, and open a Pull Request!
5. Remember: Don't edit files in the root `arena/` directly—keep your changes inside `SOLUTIONS/<your-github-username>_solutions/` so everyone's work stays clean and conflict-free.
